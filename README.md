# 🍀 THE RESPAWN — Трекер Восстановления

**THE RESPAWN** — это приватный, открытый и невероятно легкий (всего ~250 КБ) PWA-трекер для борьбы с порнозависимостью и восстановления нейробиологии мозга. 

Приложение создано с нуля без использования тяжелых фреймворков (React, Vue и т.д.) и работает полностью на стороне клиента.

## 🔒 Почему это безопасно? (Приватность)
В сфере отказа от зависимости приватность — это святое. В этом приложении **нет серверов, баз данных и облачных хранилищ**.
* **Данные только у вас:** Вся история хранится исключительно в `localStorage` вашего браузера.
* **Работает офлайн:** Благодаря Service Worker (`sw.js`), приложение не требует интернета для работы. Оно физически не может отправить ваши данные.
* **Нет аналитики и рекламы:** В коде нет скриптов Google Analytics, Facebook Pixel или рекламных сетей.
* **Открытый исходный код:** Вы можете проверить каждый файл в этом репозитории на наличие вредоносного кода.

## ⚡ Основные фичи
* **⚔️ RPG-система:** 7 шкал восстановления (ПФК, Дофамин, Энергия и др.), звания и уровни (XP).
* **🎨 Карта Периодов:** Интерактивная визуализация прогресса (90, 180, 365 дней) в виде цифр. Поддерживает режим «Сапер» и тепловую карту сложности.
* **📅 Календарь и КПТ-дневник:** Оценка сложности дня по 5-балльной шкале, заметки и отслеживание триггеров.
* **📚 База знаний:** Встроенный справочник по нейробиологии зависимости из 102 терминов.
* **🏆 Зал Славы:** Более 150 достижений.
* **⚙️ Тотальная кастомизация:** Более 70 настроек интерфейса (темы, цвета, прозрачность, звуки).

## 🛠 Технический стек
* **HTML5 / CSS3**
* **Vanilla JavaScript** (Чистый ES6+)
* **PWA** (Progressive Web App) с поддержкой офлайн-режима
* Хранение данных: `window.localStorage`

## 📲 Как установить (PWA)
Приложение не нужно скачивать как APK или IPA. Оно устанавливается прямо из браузера:
1. Откройте ссылку: **[https://ixiozi.github.io/THERESPAWN/](https://ixiozi.github.io/THERESPAWN/)**
2. **Android (Chrome):** Нажмите «Установить приложение» в нижней панели или в меню браузера.
3. **iOS (Safari):** Нажмите кнопку «Поделиться» ➔ «На экран "Домой"».

> ⚠️ **Важно:** Регулярно делайте бэкап данных в настройках приложения (Настройки -> Данные -> Создать бэкап). Это спасет вашу историю при очистке кэша браузера или смене устройства.
